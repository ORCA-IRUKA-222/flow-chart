# フローチャート

PC とタブレットで同期して使える、無限キャンバスのフローチャート作成アプリです。

- 上下左右どこまでも広がるキャンバス（パン・ズーム）
- タブレットでペン書き →「整形 OCR」ボタンで、手書きの図形・矢印・文字がきれいなフローチャートになる
- ノードの端の ○ をドラッグするだけで線を引ける。ドラッグで移動、角の ■ で大きさを変更
- ノードはいくつでも作れる（画面外のものは描画を省くので、数千個でも軽く動く）
- PC とタブレットでリアルタイム同期（オフライン中の変更は、つながったときに自動で送信）
- ボード（空間）を複数作って切り替え・名前変更・削除。サーバーに自動保存

## 起動

Node.js 18 以上が必要です。

```bash
npm install
```

```bash
npm start
```

起動すると、次のように表示されます。

```
フローチャートアプリを起動しました
  この PC から:        http://localhost:8787
  タブレットなどから:  http://192.168.x.x:8787
```

PC では `http://localhost:8787`、タブレットでは同じ Wi-Fi につないで `http://192.168.x.x:8787` を開きます。
両方で同じボードを開くと、変更がすぐにもう一方へ反映されます。データは `data/` フォルダに JSON で保存されます。

タブレットでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

## 使い方

| やりたいこと | PC | タブレット |
| --- | --- | --- |
| ノードを追加 | 空白をダブルクリック / 上部の ＋ ボタン | 空白をダブルタップ / ＋ ボタン |
| 文字を編集 | ダブルクリック / Enter | ダブルタップ / 下のバーの ✎ |
| 移動 | ドラッグ（Alt を押すと吸着なし） | 指やペンでドラッグ |
| 線を引く | ノードの ○ を別のノードへドラッグ | 同じ |
| 線の先に新しいノード | ○ を空白へドラッグ / ○ をクリック / Tab | ○ を空白へドラッグ / ○ をタップ |
| 画面の移動 | 空白をドラッグ / ホイール | 指 1 本でドラッグ |
| 拡大・縮小 | Ctrl + ホイール / トラックパッドのピンチ | 指 2 本でピンチ |
| 複数選択 | Shift + クリック / Shift + 空白ドラッグで範囲選択 | — |
| 削除 | Delete / 下のバーのゴミ箱 | 下のバーのゴミ箱 |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z | 上部の ↶ ↷ |

選択すると下にバーが出て、形（処理・開始/終了・分岐・入出力など）、色、線の種類（カギ線・直線）、矢印の向きを変えられます。

その他のキー: `V` 選択ツール、`P` ペンツール、`F` 全体表示、`R` 整形、`Ctrl+D` 複製、矢印キーで少しずつ移動。

### 手書きで描いて整形する

1. 「ペン」ツールにする（タブレットのペンなら「選択」ツールのままでも、空白に書けばインクになります）
2. 四角・角丸・ひし形・楕円・平行四辺形を描き、中に文字を書く
3. 図形どうしを線でつなぐ（矢じりは書いても書かなくても可。書いた側が矢印の先になります）
4. 線の近くに書いた文字は線のラベル（「はい」「いいえ」など）、どこにも属さない文字はテキストになります
5. 「整形 OCR」を押す

整形すると、図形はグリッドに合わせてサイズがそろい、近いノードは中心線がそろうように並びます。
既存のノードの間に線を書いたり、既存のノードの中に文字を書いたりしても認識します。
認識できなかった線や文字は手書きのまま残るので、書き直してもう一度押せます。
ペンを使っているときは、画面に触れた指（手のひら）では描かれず、画面の移動になります。

## 文字認識について

図形と矢印の判定は端末の中で行います。文字の認識は次の順に試します。

1. ブラウザ内蔵の手書き認識（Chrome の一部環境で利用可能。端末の外に送りません）
2. サーバー経由で Google の手書き入力サービスに筆跡（座標の列）を送って認識

2 を使うとき、筆跡データが Google に送られます。サーバーがインターネットにつながっていないと文字は認識されず、手書きのまま残ります（図形と線の整形はできます）。
`HANDWRITING_ENDPOINT` で同じ形式の別サービスに差し替えられます。

## 設定（環境変数）

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | `8787` | ポート番号 |
| `HOST` | `0.0.0.0` | 待ち受けるアドレス（`127.0.0.1` にすると、この PC からのみ） |
| `DATA_DIR` | `./data` | ボードの保存先 |
| `FLOW_TOKEN` | なし | 設定すると、開くときに合言葉が必要になります |
| `HANDWRITING_ENDPOINT` | Google 手書き入力 | 文字認識サービスの URL |

例:

```bash
FLOW_TOKEN=好きな合言葉 PORT=3000 npm start
```

### 外出先からも使うには

インターネットに公開する場合は、必ず `FLOW_TOKEN` を設定し、HTTPS（リバースプロキシや Cloudflare Tunnel など）経由で公開してください。
HTTPS で開くと、オフラインでもアプリ自体を開けるようになります（サービスワーカー）。

## 同期のしくみ

- 変更は「ノード / 線ごとの操作」として WebSocket で送られ、サーバーが他の端末へ配ります。
- 各要素は論理時刻で「後から変更した方が勝つ」ので、届く順番が違っても全端末が同じ状態になります。
- 送信待ちの変更と、開いたボードの内容は端末（IndexedDB）にも保存されます。オフラインでも編集でき、再接続時に自動で送られます。
- 削除したボードは記録され、古い端末から送られても復活しません。
- 「書き出し」で JSON に保存し、「読み込み」で新しいボードとして取り込めます（バックアップ用）。

```
server/      HTTP・WebSocket サーバー、保存、文字認識の中継
shared/      サーバーとブラウザで共通の操作ロジック（同期の核）

  js/canvas.js     無限キャンバス・操作
  js/recognize.js  手書きの図形・矢印・文字の判定と整列
  js/sync.js       同期・オフライン送信待ち
test/        テスト
```
