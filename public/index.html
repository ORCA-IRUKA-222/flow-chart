    リポジトリとトークンの作り方
    1. GitHub で新しいリポジトリを Private（非公開） で作る（名前は例: flow-chart-data）
    2. Fine-grained token の作成画面で、Repository access を「Only select repositories」にしてそのリポジトリだけを選ぶ
    3. Permissions の Repository permissions で Contents を「Read and write」にして作成
    4. 表示されたトークンを上に貼り付ける（各端末で1回）

    ペンのボタンを確認

    下の枠の上で、まずペン先で枠を軽くなぞってください（ペンとして届いているかの確認）。
    次に、ペン先を少し浮かせたままサイドボタンを1つずつ押し、そのあとボタンを押したまま枠をなぞってください。
